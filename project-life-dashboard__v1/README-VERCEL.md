# Vercel Deployment (Mobile)

Diese Mobile-Version ist eine reine statische Seite.

## Deploy-Schritte (Vercel)

1. Vercel öffnen → **Add New Project**
2. Repository wählen (oder „Import Git Repository“)
3. **Root Directory** auf `project-life-dashboard-de/mobile` setzen
4. Framework: **Other** (oder Static)
5. Deploy

## Ergebnis

Du bekommst eine feste URL wie `https://project-life-mobile.vercel.app`.

## Optional: Eigene Domain

Im Vercel Projekt → **Settings → Domains** → Wunschdomain hinzufügen.
